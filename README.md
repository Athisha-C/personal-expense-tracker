
# Personal Expense Tracker with CSV

## Project Description

Personal Expense Tracker is a Python-based application used to record and manage daily expenses by category.

It stores expense details in a CSV file for permanent storage.

## Features

- Add new expenses
- View all expenses
- Filter expenses by category
- Filter expenses by month
- Category-wise spending summary
- Calculate grand total
- Find the biggest single expense
- Validate dates and amounts
- Automatically create CSV file if it does not exist

## Technologies Used

- Python
- CSV Module
- Datetime Module
- Pathlib Module
- Visual Studio Code

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

python expense_tracker.py

## CSV Format

date,category,description,amount
